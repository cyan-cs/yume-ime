# Changelog

このファイルには、このプロジェクトの主な変更を記録します。

形式は [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/) に基づいています。
また、このプロジェクトは Semantic Versioning を採用しています。

## [Unreleased]

### Added

- 数字入力の composing 中にも予測候補が開くようになり、連続した数字も候補選択ショートカットだけでなく通常入力として継続できるようになりました。
- 大文字ローマ字入力、半角数字処理、ハイフン処理、波かっこ入力に対する回帰テストを追加しました。
- Shift を押しながらの英字入力では、大文字を保持したままローマ字変換できるようになりました。
- 数字入力は入力時に半角数字へ正規化されるようになりました。
- 全角直接入力は ASCII 英字のみに適用されるようになりました。数字は直接入力では半角のままとなり、全角数字は変換候補として表示されます。
- ひらがな入力モードでは、ハイフン (`-`) が長音記号 (`ー`) として確定されるようになりました。
- 波かっこ (`{` `}`) は半角のまま確定されます。
- v1.0.0 での実用性向上に向けて、予測変換の並び順を日本語の文法に寄せて改善しました。直前の助詞や文末表現に応じて、名詞・動詞・助詞・語尾の候補順位がより自然になるよう調整しています。
- `を` `の` `は` `が` `も` `に` `で` `へ` `と` に加えて、`には` `では` `とは` `ので` `のに` などの複合助詞の後続候補も調整され、文脈に合わない生読み候補やローマ字・カタカナの補助候補は上位に出にくくなりました。
- composing 中の短い読みでは候補数を抑え、読みが伸びると候補を広げるようにして、短い入力段階でのノイズを減らしつつ必要な候補数は維持するようにしました。
- 変換開始時の文節分割は前後の品詞関係を見ながら決まるようになり、`名詞 + 助詞`、`動詞語幹 + ます`、`名詞 + です` のような基本的なつながりを初期状態から選びやすくなりました。
- 変換中に前の文節候補を変更した場合は後続文節の候補が新しい文脈で再評価されるようになり、さらに次文節の候補は先読みして準備されるため、連続変換時の追従性も改善しました。
- v1.0.0 での実用性向上に向けて、予測変換の並び順を日本語の文法に寄せて改善しました。直前の助詞や文末表現に応じて、名詞・動詞・助詞・語尾の候補順位がより自然になるよう調整しています。
- `を` `の` `は` `が` `も` `に` `で` `へ` `と` に加えて、`には` `では` `とは` `ので` `のに` などの複合助詞の後続候補も調整され、文脈に合わない生読み候補やローマ字・カタカナの補助候補は上位に出にくくなりました。
- composing 中の短い読みでは候補数を抑え、読みが伸びると候補を広げるようにして、短い入力段階でのノイズを減らしつつ必要な候補数は維持するようにしました。
- 変換開始時の文節分割は前後の品詞関係を見ながら決まるようになり、`名詞 + 助詞`、`動詞語幹 + ます`、`名詞 + です` のような基本的なつながりを初期状態から選びやすくなりました。
