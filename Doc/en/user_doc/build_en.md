# Build Instructions

## Build Only
Open PowerShell and move to the root of this repository.

1. Run `build.ps1`
```powershell
.\scripts\build.ps1
```

## Build and Register in the Registry
Open **PowerShell as Administrator** and move to the root of this repository.

1. Run `register-YumeIME.ps1`
```powershell
.\scripts\register-YumeIME.ps1
```

## Unregister from the Registry
To remove the IME that was registered using `register-YumeIME.ps1`.
Open **PowerShell as Administrator** and move to the root of this repository.

1. Run `unregister-YumeIME.ps1`
```powershell
.\scripts\unregister-YumeIME.ps1
```
