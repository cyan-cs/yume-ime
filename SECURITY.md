# Security Policy

## Supported Versions

Currently, only the latest version is supported.

|Version |Supported|
|----------|----------|
|Latest | ✅ |

## Vulnerability Reporting

If you discover a vulnerability, please report it using one of the following methods:

- GitHub Issues

### Information to Include in Your Report

- Problem Summary
- Steps to Reproduce
- Impact (if determined)

After reviewing your report, we will take appropriate action.
